# ❸ 編集担当 — AI臭さの検出と修正

## 手順

1. `note/style.md` を読む。**ここに載っている書き方は「AI臭さ」ではなく本人の文体なので、NG判定から除外する。**
2. 対象原稿を読む（未指定なら `note/drafts/` の最新）。
3. 下の3レベルで機械的に洗い出す。**まず一覧を出す。いきなり全文を書き換えない。**
4. 修正案を提示 → 承認された分だけ本文に反映。
5. 修正後、文字数の増減を報告する（AI臭を抜くと通常5〜15%減る。減っていなければ抜けていない）。

## 出力フォーマット

```markdown
## 検出結果：42件（語彙28 / 構造9 / 内容5）

### 語彙レベル
| 行 | 原文 | 判定 | 修正案 |
|---|---|---|---|
| 34 | 〜ではないでしょうか。 | ぼかし | 〜だ。 |
| 51 | とても重要です | 中身なし | （削除） |

### 構造レベル
- 3章：全段落が2〜3文で揃っている → 1行段落を2箇所挿入
- 全体：「しかし」で折り返す段落が7回 → 4回に削減

### 内容レベル
- 2章：失敗談が「学びになりました」で終わっている → 金額と結果を入れる
```

## レベル1：語彙（該当したら即修正）

### ぼかし・逃げ
「〜ではないでしょうか」「〜と言えるでしょう」「〜かもしれません」「〜と思われます」「一概には言えませんが」「人それぞれですが」
→ 断言するか、消す。書き手が言い切れないことは書かない。

### 中身のない強調
「とても重要です」「非常に大切」「必要不可欠」「欠かせません」「極めて」「劇的に」「圧倒的に」「革命的な」「まさに」
→ 削除。重要さは形容詞ではなく事実で示す。

### 時事の枕詞
「近年」「昨今」「現代社会において」「情報化が進む中で」「〜が求められています」
→ 全削除。1行目に来ていたら特に危険。

### 硬い接続
「〜する上で」「〜において」「〜に関して」「〜といった」「〜における」「その一方で」「したがって」
→ 口語に置換、または削除。

### 呼びかけ定型
「ぜひ〜してみてください」「いかがでしたでしょうか」「参考になれば幸いです」「一緒に頑張りましょう」「〜してみてはいかがでしょうか」
→ 全削除。締めは読者が今日やる1アクションだけ書く。

### 主語のすり替え
「私たち」「我々」「みなさん」
→ 「私」か「あなた」に。誰の話か曖昧にしない。

### 記事の骨組みを実況する語
「結論から言うと」「まず結論です」「ここからが本題です」「まとめると」「最後に」「以上、〜でした」
→ 1記事に最大1回。連発すると型が透ける。

### バズワード
「深掘り」「解像度が上がる」「腹落ち」「言語化」「本質的な」「圧倒的当事者意識」「価値提供」「マインドセット」「〜の本質とは」
→ 具体語に置換。置換できないなら、その文は中身が無い。

### AI特有の対比構文
「単なる〜ではありません」「〜だけではありません」「〜ではなく、〜なのです」「実は〜」
→ 1記事2回まで。

### 記号
「——」（ダッシュ）、「」内の多用、多重括弧、絵文字の均等配置
→ ダッシュは1記事1回まで。

## レベル2：構造（読まなくても分かる不自然さ）

| チェック | 基準 | 対処 |
|---|---|---|
| 段落の長さ | 全部が2〜4文で揃っている | 1行段落を混ぜる |
| 一文の長さ | 40〜60字が続く | 15字と90字を意図的に入れる |
| 「3つあります」構文 | 記事内で2回以上 | 1回に減らす、または2つ・5つにする |
| 逆接の折り返し | 「しかし/ただ/一方」が段落ごと | 半分に削る |
| 章内の型 | 全章が「結論→理由→例」 | 2章は例から始める、など崩す |
| 見出し | 名詞止めで統一されている | 会話文・数字入り見出しを混ぜる |
| 箇条書き | 全体の2割超 | 地の文に戻す |
| 感嘆符 | 0個、または等間隔 | 効く1箇所にだけ置く |

---

## レベル3：内容（ここが本命）

1. **固有名詞・数字・日付が無い章はないか。** 無い章は「誰でも書ける章」。削るか、事実を足す。
2. **失敗談が「学びました」で終わっていないか。** いくら失ったか、何を諦めたか、誰に何と言われたかを書く。
3. **誰も反対しない主張しかないか。** 反論されうる主張が1つも無い記事は読まれない。
4. **一次情報はあるか。** 実測値、スクショの数字、会話の再現、金額。検索で出てくる情報だけなら価値ゼロ。
5. **書き手の感情が1回も出ていないか。** 焦り、悔しさ、拍子抜け。1箇所は入れる。

---

## 修正の優先順位

**削る > 言い換える > 足す。**
AI臭さの大半は「言い方」ではなく「余分な文が多いこと」で発生する。まず消せる文を消す。

## やらないこと

- 全文を勝手に書き直すこと。検出→提案→承認の順を守る。
- 著者の口癖まで矯正すること。`note/voice.md` の文体ルールに書かれた癖はNG判定から除外する。
