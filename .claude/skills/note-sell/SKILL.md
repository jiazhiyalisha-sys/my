# ❻ 販売担当 — タイトル案と有料ラインの設計

## 手順

1. 原稿（`note/drafts/` の最新）と `note/voice.md` の「商品・収益導線」を読む。
2. タイトル20案を出す → 上位3案を推薦。
3. 有料ライン位置を提案する（**原稿の実際の行を指定する**。「3章のあたり」のような曖昧な指定はしない）。
4. 価格を根拠付きで提案する。
5. 見出し（ヘッダー画像文言）とリード文を作る。

---

## A. タイトル20案

### 型を散らす（同型3本まで）

| 型 | 例 |
|---|---|
| 数字＋損失 | 40万円溶かして分かった、広告を止める判断基準 |
| 否定 | 「毎日投稿」をやめたら、フォロワーが増えた |
| 期間＋結果 | 3ヶ月42本書いて、伸びたのは4本だった |
| 対象名指し | 反応ゼロで2ヶ月目に入った人へ |
| 手順の約束 | 反応が出ない投稿を、2時間で作り直す手順 |
| 疑問 | なぜあなたの投稿は最後まで読まれないのか |
| 告白 | 正直に書く。私の記事が読まれなかった本当の理由 |
| 比較 | 伸びる人と伸びない人の差は、才能ではなく1行目だった |

### タイトルの制約

- **32字以内**（noteのタイムラインで切れない長さ）。
- **数字を入れる案を最低8本。**
- 「〜の方法」「〜のコツ」「〜まとめ」「完全版」「徹底解説」は使わない。
- 疑問形は3本まで（多いと弱く見える）。
- **1行目（導入の書き出し）とセットで評価する。** タイトルだけ強くて中身が追いつかないものは落とす。

出力は表形式で、各案に「型」「字数」「刺さる読者」を併記。最後に推薦3案とその理由。

---

## B. 有料ラインの設計

### 原則

**無料部分＝「効く」ことの証明。有料部分＝「やり方」。**

| 無料に置く | 有料に置く |
|---|---|
| 読者の現状の名指し | 具体的な手順・テンプレ |
| 問題の再定義（常識の否定） | 実数値・単価・スクショ |
| 自分の失敗の全容 | 失敗を回避するチェックリスト |
| 結果（何がどう変わったか） | 判断基準・分岐の条件 |
| 転換点の「気づき」 | その気づきの実装方法 |

### ライン位置の決め方

1. 無料部分だけ通しで読み、**「面白かった。で、どうやるの？」で終わるか** を確認する。
   - 「なるほど、分かった」で終わる → ラインが遅すぎる。前に戻す。
   - 「何の話か分からない」で終わる → ラインが早すぎる。後ろに送る。
2. **無料部分は全体の30〜40%**（8,000字なら2,400〜3,200字）を目安にする。
3. ラインの直前に「ここから先で何が手に入るか」を3行で置く。箇条書き3〜5項目。
4. ライン直後の1文は、**購入者が「買ってよかった」と3秒で思う一番具体的な情報**にする。前置きから始めない。

出力では `原稿の◯行目「〜」の直後` と行番号で指定し、その位置にした理由を書く。代替案を1つ添える。

---

## C. 価格

以下を根拠として提示する（勘で数字を出さない）。

- 読者が**この記事で回避できる損失額**（自分が失った金額が基準になる）
- 同ジャンルの相場（500 / 980 / 1,500 / 2,000 / 3,000円のどの帯か）
- `voice.md` の商品への導線があるか（あるなら安く設定して入口にする）
- 収録している一次情報の量（実数値・テンプレが多いほど上げられる）

**「返金保証」「先着◯名値上げ」は、実際に運用する気がないなら書かない。**

---

## D. 見出し・リード

- **ヘッダー画像の文言**：タイトルと別の言葉にする（同じ文字を2回見せない）。10字以内。
- **リード文（冒頭3行）**：読者の状況の名指し → 結果の提示 → この記事で渡すもの。ここに「この記事では〜について解説します」は書かない。
- **販売用のThreads告知文**：❶投稿担当の「告知」型に渡す1行を作る。
