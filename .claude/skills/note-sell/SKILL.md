# ❻ 販売担当 — タイトル案と有料ラインの設計

## 手順

1. 原稿（`note/drafts/` の最新）と `note/voice.md` の「商品・収益導線」を読む。
2. タイトル20案を出す → 上位3案を推薦。
3. 有料ライン位置を提案する（**原稿の実際の行を指定する**。「3章のあたり」のような曖昧な指定はしない）。
4. 価格を根拠付きで提案する。
5. 見出し（ヘッダー画像文言）とリード文を作る。

---

## A. タイトル20案

### 型を散らす（同型3本まで）

| 型 | 例 |
|---|---|
| 数字＋損失 | 副業に150万払って、手元に残ったのは領収書だけだった |
| 否定 | 「常勤に戻れば安定する」と思っていた9ヶ月前の私へ |
| 期間＋結果 | コミュ障を直すのに4年かかった。最初の1年でやるべきだったこと |
| 対象名指し | 夜勤明けに求人サイトを閉じている看護師へ |
| 手順の約束 | 職場で誰とも話せない日を、3ヶ月で減らした手順 |
| 疑問 | なぜ副業は、いつも3ヶ月でやめてしまうのか |
| 告白 | 8年目の看護師が、月35万で非常勤を選んだ理由 |
| 比較 | 辞めて後悔する人と、しない人の違いは1つだけだった |

### タイトルの制約

- **32字以内**（noteのタイムラインで切れない長さ）。
- **数字を入れる案を最低8本。**
- 「〜の方法」「〜のコツ」「〜まとめ」「完全版」「徹底解説」は使わない。
- 疑問形は3本まで（多いと弱く見える）。
- **1行目（導入の書き出し）とセットで評価する。** タイトルだけ強くて中身が追いつかないものは落とす。

出力は表形式で、各案に「型」「字数」「刺さる読者」を併記。最後に推薦3案とその理由。

## B. 有料ラインの設計

### 原則

**無料部分＝「効く」ことの証明。有料部分＝「やり方」。**

| 無料に置く | 有料に置く |
|---|---|
| 読者の現状の名指し | 具体的な手順・テンプレ |
| 問題の再定義（常識の否定） | 実数値・単価・スクショ |
| 自分の失敗の全容 | 失敗を回避するチェックリスト |
| 結果（何がどう変わったか） | 判断基準・分岐の条件 |
| 転換点の「気づき」 | その気づきの実装方法 |

### ライン位置の決め方

1. 無料部分だけ通しで読み、**「面白かった。で、どうやるの？」で終わるか** を確認する。
   - 「なるほど、分かった」で終わる → ラインが遅すぎる。前に戻す。
   - 「何の話か分からない」で終わる → ラインが早すぎる。後ろに送る。
2. **無料部分の目安：300円なら50〜60%、500円なら30〜40%。**
   安い記事ほど無料を厚くする。300円は「買ってもらう」より「買う癖をつけてもらう」ための価格。
3. ラインの直前に「ここから先で何が手に入るか」を3行で置く。箇条書き3〜5項目。
4. ライン直後の1文は、**購入者が「買ってよかった」と3秒で思う一番具体的な情報**にする。前置きから始めない。

出力では `原稿の◯行目「〜」の直後` と行番号で指定し、その位置にした理由を書く。代替案を1つ添える。

## C. 価格

現在の販売帯は **300円 / 500円 の2つだけ**（`voice.md`）。この2択で提案する。
目標は1本あたり **50部**。つまり300円なら15,000円、500円なら25,000円。

| | 300円 | 500円 |
|---|---|---|
| 中身 | 体験談が主軸。読み物として完結する | 手順・チェックリスト・判断基準が入る |
| 使い方 | **初めて買う人の入口。** 買う心理的ハードルを下げる | 300円を買った人の2本目 |
| 目安 | 一次情報1本（1つの失敗を掘る） | 一次情報3本以上＋再現できる手順 |

判断基準：**読者がこの記事を読んで「明日やること」が具体的に決まるなら500円、
「自分だけじゃなかった」で価値が完結するなら300円。**

50部を狙うなら、300円を先に複数本並べて購入のハードルを下げるほうが早い。
1本を高くするより、買われる本数を増やす設計を優先する。

**「返金保証」「先着◯名値上げ」は、実際に運用する気がないなら書かない。**

---

## D. 見出し・リード

- **ヘッダー画像の文言**：タイトルと別の言葉にする（同じ文字を2回見せない）。10字以内。
- **リード文（冒頭3行）**：読者の状況の名指し → 結果の提示 → この記事で渡すもの。ここに「この記事では〜について解説します」は書かない。
- **販売用のThreads告知文**：❶投稿担当の「告知」型に渡す1行を作る。
