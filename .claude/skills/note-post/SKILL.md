# ❶ 投稿担当 — Threads 10本一括生成

## 手順

1. `note/voice.md` を読む。読者・文体・実績が空欄なら、埋めるよう1回だけ促してから、暫定で進める。
2. `note/analytics/log.csv` があれば直近の勝ち投稿を確認し、勝ち型を1〜2本混ぜる。
3. テーマが指定されていなければ、`note/themes/` の企画ストックか直近の note 原稿から拾う。
4. 下の型リストから **10本すべて違う型** で生成する。同じ型の重複禁止。
5. `note/threads/YYYY-MM-DD.md` に保存する。

## 10本の型（1本ずつ割り当てる）

| # | 型 | 骨格 |
|---|---|---|
| 1 | 断言 | 世間の常識を1行で否定 → 理由1つ → 自分の実例 |
| 2 | 失敗談 | いつ・いくら・何を失ったか → 原因 → 今やっていること |
| 3 | 数字 | 具体数字から入る（「3ヶ月で42本」） → 内訳 → 分かったこと |
| 4 | 逆張り | みんながやっている手法を名指し → なぜ効かないか → 代案 |
| 5 | 問いかけ | 読者が答えに詰まる質問 → 自分の答え → 判断基準 |
| 6 | 手順リスト | 「〜のやり方」3〜5ステップ。抽象語を1つも入れない |
| 7 | 実況 | 今日やったことの生ログ。時刻・作業・結果 |
| 8 | 比較 | 「Aの人」と「Bの人」の分岐点を1つだけ提示 |
| 9 | 再現会話 | クライアント/知人との会話をそのまま引用 → 気づき |
| 10 | 告知 | note本文の一番おいしい1行だけ抜いて、リンク導線 |

## 1本あたりの制約

- **500字以内**。ただし1〜3行の短文も混ぜる（全部長文にしない）。
- **1行目で完結させる**。1行目だけ読んで意味が通らない投稿はボツ。
- 1投稿につき主張は1つ。詰め込まない。
- ハッシュタグは付けない（Threadsでは効かない）。
- 絵文字は使うなら1投稿に1つまで。10本中3本以内。
- 「いかがでしょうか」「ぜひ」「〜だと思います」は使わない。

## 出力フォーマット

```markdown
# Threads投稿案 YYYY-MM-DD / テーマ：○○

## 1.【断言】
（本文）
- 字数：◯◯字
- 狙い：（保存狙い / 返信狙い / プロフ誘導）
- 推奨投稿：◯曜 ◯時

## 2.【失敗談】
...
```

最後に **投稿順の推奨** を1ブロックで付ける。
基本形：断言 → 失敗談 → 数字 → 実況 → 問いかけ → 手順 → 逆張り → 比較 → 再現会話 → 告知。
告知は必ず最後（先に告知すると以降が伸びない）。

## やらないこと

- 10本を1つのテーマの言い換えで埋めること。切り口を変える。
- 数字の捏造。実績が無い項目は「◯◯（要記入）」と穴あきで出す。
