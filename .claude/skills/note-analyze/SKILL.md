# ❹ 分析担当 — 伸びた投稿を分析して次に活かす

## 手順

1. `note/analytics/log.csv` を読む。無ければヘッダ付きで作る。
2. 数値が渡されていなければ、**何を貼ればいいか具体的に指示する**（下記「必要な数値」）。
3. 数値を追記する。
4. 分析を出す。
5. **`note/voice.md` の「6. 過去の勝ちパターン」に追記する。** ここまでやって初めて「次に活かす」になる。追記しないなら分析していないのと同じ。

## 必要な数値

**Threads**：日付 / 型 / 1行目 / インプレッション / いいね / 返信 / リポスト / プロフィールアクセス / フォロー増
**note**：日付 / タイトル / 全体ビュー / 読了率 / スキ / フォロー増 / (有料なら) 購入数・売上

## log.csv フォーマット

```csv
date,platform,type,hook,impressions,likes,replies,reposts,profile_clicks,follows,views,read_rate,purchases,revenue,note
2026-09-01,threads,失敗談,40万円かけて集めた見込み客が0人だった,12400,310,42,18,220,26,,,,,
2026-09-03,note,,3ヶ月で42本書いて分かったこと,,540,,,,31,2100,38%,14,42000,
```

## 分析の型

数字を並べるだけの報告は禁止。必ず次の4点を出す。

### 1. 順位と外れ値
上位3本・下位3本を出す。**中央値の3倍を超えた投稿は「外れ値」として別扱い**にする。外れ値を平均に混ぜると全体像が歪む。

### 2. 伸びた要因の分解
上位3本について、以下のどれで伸びたかを切り分ける。
- **1行目**（フック）… インプレッションが高い＝1行目が効いた
- **本文**（中身）… いいね率／返信率が高い＝読み切られた
- **導線**（着地）… プロフクリック率・フォロー率が高い＝着地が効いた

インプレッションだけ高くてフォローが増えていない投稿は「バズったが失敗」。ここを混同しない。

### 3. 再現可能な要素の抽出
「面白かったから」は要因ではない。次の粒度まで落とす。
- 使った型（断言／失敗談／数字…）
- 1行目の構文（例：「数字＋否定」）
- 具体的な金額・期間の有無
- 投稿曜日・時刻
- 文字数帯

### 4. 次の打ち手（3つまで）
- 次に増やす型：
- 次にやめる型：
- note化する価値があるThreads投稿：（反応が良い＝需要が実証済み。これが❺企画担当への引き継ぎ材料になる）

```markdown

- 外れ値：1本（#3）
```

## 注意

- **数字を推測で埋めない。** 未提供の項目は空欄のまま扱う。
- 1回の分析で最低5本、できれば10本以上を対象にする。2〜3本では偶然と区別できない。
- 「バズ＝成功」としない。目標は `note/voice.md` の「1本あたりの目標」に書かれた指標。
