# /タイトル — noteタイトル 毎日10本

**書く前にタイトルを量産する。** 反応が取れそうなタイトルから逆算して記事を選ぶための在庫作り。
`$ARGUMENTS` に方向性の指定があれば踏まえる。無ければ素材から自動で散らす。

出力は `note/titles/YYYY-MM-DD.md`、ストックは `note/titles/stock.md` に追記。

---

## 実行前に必ずやること

1. `note/voice.md` を読む（素材＝失敗3つ・実績の数字・読者・禁止事項）。
2. **`note/titles/stock.md` の既存タイトルを全部読む。** 毎日10本出すと重複が最大の敵になる。
   - 同じ「素材 × 角度」の組み合わせは二度使わない
   - 言い回しが違うだけの実質重複は出さない
3. `note/analytics/log.csv` があれば、伸びたタイトルの構文を1〜2本の型として混ぜる。

---

## 素材 × 角度で作る（これが毎日10本の燃料）

素材は3つしかない。だが角度は8つある。**3 × 8 = 24通り**、読者を看護師／会社員で振れば48通り。
「素材が尽きた」は角度を変えていないだけ。

### 素材（`voice.md` より）
- **A**：副業に150万払って騙された
- **B**：看護師を辞めて9ヶ月、異業種を経て復帰 → 今年4月から非常勤
- **C**：人見知り・コミュ障を直すのに4年かかった

### 角度
| | 角度 | 何を書くか |
|---|---|---|
| 1 | 直前 | そうなる**前**に何を考えていたか |
| 2 | その後 | 結果、今どうなっているか |
| 3 | 金額・数字 | いくら・何ヶ月・何人 |
| 4 | 感情 | 恥ずかしさ、怒り、拍子抜け、安堵 |
| 5 | 他者視点 | 周りに何と言われたか。言われて効いた一言 |
| 6 | if | あの時こうしていれば。今なら何を選ぶか |
| 7 | 対比 | 同じ状況で分かれた人との違い |
| 8 | 手順 | 同じ状況の人が今日やること |

**10本のうち、同じ素材は最大4本まで。** 3素材すべてを必ず使う。

---

## タイトルの制約

- **32字以内**（noteのタイムラインで切れない）
- **数字入りを最低4本**
- 型を散らす（同型は最大3本）
  数字＋損失／否定／期間＋結果／対象名指し／手順の約束／疑問／告白／比較／セリフ／時系列
- 疑問形は3本まで
- 使わない：「〜の方法」「〜のコツ」「完全版」「徹底解説」「〜まとめ」
- **`voice.md` の禁止事項を守る**：自慢話にしない。読者を否定しない。
  - ✕ 副業で150万溶かす人の共通点（読者を裁いている）
  - ○ 副業に150万払った私が、契約前に見落としていたこと

## 出力フォーマット

```markdown
# noteタイトル案 2026-09-10（10本）

| # | タイトル | 字数 | 素材 | 角度 | 型 | 想定価格 | 必要な素材 |
|---|---|---|---|---|---|---|---|
| 1 | 副業に150万払った日、私は領収書すら貰わなかった | 26 | A | 4感情 | 告白 | 300円 | 支払日・支払方法 |
| 2 | ... | | | | | | |

## 今日書くならこの3本
1. #1 — 素材が手元に完結していて、確認事項ゼロ。今日すぐ書ける
2. #6 — 読者の「私なんて」に直接当たる
3. #9 — 有料500円にできる（手順が入る）

## 保留
- #4 — 素材Bの角度3と近い。stock.mdの9/3 #2 と実質重複ぎみ
```

最後に `note/titles/stock.md` へ追記する（未使用／執筆中／公開済みの状態つき）。

---

## 運用のコツ

- **10本すべてを書く必要はない。** 在庫として貯めて、月に2〜4本だけ書く。
- タイトルだけ Threads に出して反応を見る手もある（`/投稿` の「問いかけ」型に流用）。
- **1本は必ず「怖くて書けないタイトル」を入れる。** 一番伸びるのはそこ。
- 書くと決めたら `/記事化 "タイトル"` に渡す。

## やらないこと

- 数字の捏造。素材に無い金額・期間をタイトルに入れない。
- 在庫を読まずに生成すること。重複は在庫の価値をゼロにする。
