# データの置き場所

`analyze_note_sales.py` は、このディレクトリ配下の `*.csv` を再帰的に読み込みます。

## ⚠ 先に確認してください

**このリポジトリは現在 public です。** `data/*.csv` は `.gitignore` で追跡対象外にしてあるので、
ここに置くだけでは公開されません。共有したい場合は、次のどちらかを選んでください。

- リポジトリを private にしてから `git add -f data/売上.csv` で追加する（推奨）
- リポジトリには置かず、チャットにCSVを添付する

note の売上CSVには購入日時などが含まれます。公開前に中身を確認してください。

## 用意するCSV（2種類、両方あると分析の精度が上がる）

### 1. 売上系（必須）

note の「ダッシュボード」→「売上管理」→ 販売履歴のダウンロード。
次のいずれかの形なら、そのまま読み込めます。

- **1行＝1購入**の明細形式（例: `日時, 種類, 商品名, 販売価格, 手数料, 振込金額`）
- **1行＝1記事**の集計形式（例: `記事タイトル, 価格, 販売数, 売上金額`）

これが無いと「売れている記事」は判定できません（販売数・売上はダッシュボードにしかないため）。

### 2. アクセス系（任意・転換率を出すのに必要）

note の「ダッシュボード」→「アクセス状況」→ CSVダウンロード。
例: `記事タイトル, 全体ビュー, コメント, スキ`

これがあると **転換率（PV→購入）** と スキ率 が算出できます。無い場合、
売上金額・販売数のランキングだけが出ます。

## 列名について

見出しの表記ゆれは自動で吸収します（`ビュー` / `全体ビュー` / `PV`、`販売数` / `購入数` など）。
文字コードは UTF-8（BOM付き含む）と Shift_JIS(cp932) の両方に対応。
見出し行の前に説明行が入っていても読み飛ばします。

うまく読めない場合は、そのCSVの1行目〜数行を共有してください。列名の対応を追加します。

## 実行

```bash
python3 analyze_note_sales.py                 # data/ 配下を全部読む
python3 analyze_note_sales.py --min-views 300 # 転換率ランキングのPV下限を変更
python3 analyze_note_sales.py --include-support  # サポート等も集計に含める
```

結果は標準出力と `reports/note_sales_report.md` に出ます。
