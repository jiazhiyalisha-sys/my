# note 有料記事 再起動プレイブック

> 1冊売れてから止まっているnoteを、売れ続ける状態に戻すための設計書。
> 2026年9月版 / note公式の手数料・価格データ準拠

公開版（読みやすいHTML）: https://claude.ai/code/artifact/30fc5cec-22b6-4bc1-9a92-0b3f495d1d3e

## 01. 原因の特定：最初の1冊は「知人＋瞬間風速」で売れている

有料記事の最初の1冊は、ほぼ例外なく公開直後の告知で届いた数十人の中から出る。この数十人は一度使い切ったら二度と発生しない。2冊目が出ないのは記事が悪いからではなく、**記事に人が流れ込む経路が公開直後の一瞬しか存在しなかった**から。

noteは記事を探す検索行動が弱く、有料記事はnote内のおすすめにも乗りにくい。有料記事を置いただけの状態は、人通りのない路地に店を出したのと同じ。やるべきは新しい有料記事を書くことではなく、店の前に道を通すこと。

### 切り分け（この順で確認する）

1. **有料記事ページのビュー数が月100未満** → 集客の問題。02〜04へ。**ここが9割**
2. **ビューはあるが購入0（購入率1%未満）** → 記事の問題。05〜07へ
3. **買われるが2本目が売れない** → 商品ラインの問題。08へ

noteダッシュボードで有料記事の月間ビュー数を確認する。二桁なら記事を書き直しても売上は動かない。

## 02. 必要なアクセス数の逆算

有料記事の購入率は販売ページのビューに対して **1〜5%**（無料部分の設計が良ければ3〜5%、弱いと1%以下）。控えめに2%で逆算する。

| 項目 | 数値 |
|---|---|
| 目標月商 | 30,000円 |
| 単価（実用系の売れ筋） | 1,800円 |
| 必要販売数 | 17冊 / 月 |
| 購入率 2% と仮定 | ÷ 0.02 |
| 有料記事ページに必要なビュー | **850 PV / 月** |
| 無料記事 → 有料記事のクリック率 10% | ÷ 0.10 |
| 無料記事に必要な合計ビュー | **8,500 PV / 月** |

月8,500PVは、1本あたり月850PVの無料記事が10本あれば届く水準。月850PVは「そこそこ読まれる無料記事」であってバズではない。**バズらずに積み上げれば到達できる**。

→ 次に書くべきは2本目の有料記事ではなく、**有料記事へ流すための無料記事10本**。
→ 有料記事と無料記事の比率は **1 : 8〜10**。

## 03. 導線マップ

```
[入口]  Google/note検索   noteのおすすめ   X     フォロワー再訪
        （悩みワード）    （一次情報）   （切り抜き） （連載・更新）
                    ↓        ↓        ↓        ↓
[信頼]  プロフィール1行目の実績 / 固定表示 / 購入者の声・実データ・失敗談
                              ↓
[販売]  有料記事（看板商品は1本に絞る）
        ← 全ての無料記事から常設リンク
        購入 → 感想依頼 → 記事に追記 → 次の購入者の判断材料（ループ）
```

### 常設導線を置く7か所（今日30分で全部できる）

1. **noteプロフィール文の1行目** — 肩書きより先に「誰の、どの悩みを、どう解決したか」を数字で。末尾に有料記事リンク
2. **クリエイターページの記事固定表示** — 上段に入口の無料記事、下段に有料記事。有料記事だけの固定は警戒される
3. **全無料記事の末尾に定型ブロック** — 「◯◯で詰まっている方へ：手順を全部まとめた記事があります」＋リンク。**過去記事にも遡って全部入れる。最大の流入源になる**
4. **無料記事の目次の直上に1行** — 「この記事は概要です。実際の手順は詳細版にあります」。最後まで読まない人を拾える
5. **無料記事＋有料記事を1つのマガジンに束ねる** — マガジンはフォローされnote内で回遊される。無料記事を入口、有料記事を最終巻に
6. **Xのプロフィール＋固定ポスト** — 固定ポストは宣伝ではなく「無料で読める要点スレッド」にし、最後に有料リンク
7. **Xの通常投稿はリンクを本文に入れずリプ欄に置く** — 本文の外部リンクは表示が伸びにくい。本文は結論だけ

## 04. 入口になる無料記事10本の型

無料記事は「有料記事と同じテーマの周辺」を埋める。バラバラのテーマだと有料記事への興味が下がる。**有料記事1本を中心に、同じ悩みを持つ人が検索する言葉で10本**。

| # | 型 | 効く理由 |
|---|---|---|
| 1 | 失敗談（同テーマで自分がやらかした話） | 一次情報として最も強く、noteのおすすめに最も乗りやすい |
| 2 | 実データ公開（◯日続けた結果、数字を全部出す） | 検証可能性があり、信頼が一度で立つ |
| 3 | 有料記事の手順のうち1つを完全無料公開 | 「残りも本物だ」という最強の購入根拠 |
| 4 | 初心者が最初にやるべき1つだけ | 検索流入が取りやすく、次の一手として有料記事が自然 |
| 5 | 用語・前提の解説 | Google検索の入口。地味だが安定して流入が続く |
| 6 | 使っている道具・ツールのレビュー | 指名検索。購買意欲の高い読者が来る |
| 7 | よくある質問へのまとめ回答 | 読者の言葉がそのままタイトルになる |
| 8 | 他の方法との比較（Aではなくなぜ B か） | 比較検討中の人を捕まえられる |
| 9 | ビフォーアフター（画面・成果物の実物） | 視覚的証明。スクショを惜しまない |
| 10 | 買ってくれた人の事例・感想の紹介 | 社会的証明。1件でも書く価値がある |

**2026年2月にnoteのおすすめ（レコメンド）は刷新され、AIが記事の中身を読んで内容に合う読者へ届ける方式になった。** note公式（CXO 深津貴之氏）が示した優先方針は「一次情報・生の体験の記録・気づき・失敗談からの学び・継続的な実験の記録・一次創作」。逆に「情報を要約し直しただけ」「AIで大量生成した重複コンテンツ」は推されにくい。上の1・2・9番が今いちばん効くのはこのため。

## 05. 無料エリアの設計：10ブロックの順番がそのまま購入率

よくある失敗は2つ。**①あらすじだけで中身が想像できない**（買う理由がない）、**②無料で満足させてしまう**（買う必要がない）。この2つを同時に避ける順番。

1. **結論の一部を数字で先に出す** — 「3か月で◯◯が△△になりました。やったのは次の4つだけです」
2. **読者の状況を言語化する** — 「◯◯を試したけど△△で止まっている」。ターゲットを1人に絞って書く
3. **なぜ自分が書けるのか（一次情報）** — 肩書きではなく「やった量」
4. **この記事を読んだ後の状態（Before → After）** — 箇条書きで4〜6個。抽象語を使わず動作で書く
5. **目次で有料部分の見出しを全部見せる** — **最重要**。中身は隠して「地図」は全部見せる
6. **ノウハウを1つだけ完全公開する** — 出し惜しみしない。ここの質が有料部分の品質保証になる
7. **向いている人／向いていない人** — 「こういう人は買わないでください」。除外は信頼を上げ、返金クレームも減る
8. **リスクを取り除く約束** — 質問対応の有無、更新方針（購入者は追記も無料で読める）、想定所要時間
9. **価格の根拠** — 「外注すると◯円／この失敗を避けられれば◯時間」。値上げ予定があるなら明記
10. **購入ボタン直前の一行** — 煽らず判断を助ける一文

```
ここから先は、私が実際に使っている手順そのものです。
先に無料部分の◯◯だけ試してみて、続きが必要だと思ったら戻ってきてください。
```

### 無料エリアの長さ

全体の **20〜30%**（全体8,000字なら1,800〜2,400字）。無料部分を読み終えた人が「やり方は分かった、でも自分のケースに落とす手順がない」状態になっていれば正解。

## 06. 有料エリアの設計：返金されず、口コミが出る中身にする

有料部分の役割は「満足」ではなく**読者が実際に動けること**。動けた人だけが感想を書き、その感想が次の購入を生む。

- **冒頭に「この記事の使い方」** — どこから手を付け、何分で何ができるか
- **手順はコピペできる粒度まで下げる** — 「分析する」ではなく、実際の文面・チェックリスト・数値基準・ボタン名まで
- **スクリーンショットと実データを惜しまない** — 文章より速く信頼が伝わる
- **失敗例を必ず入れる** — 成功事例だけの記事は薄く見える
- **巻末に質問窓口と更新履歴** — 「生きている記事」に見え、値上げの正当化にもなる
- **購入者特典を1つ** — テンプレ、チェックリスト、相談1回。感想を書いてもらう口実にもなる

### 感想を依頼する文面（巻末に置く）

```
最後まで読んでいただきありがとうございます。
もしこの記事が役に立ったら、Xで「#(あなたのタグ)」を付けて
一言だけ感想をいただけると嬉しいです。
いただいた感想は（許可をとって）この記事にも追記していきます。
```

1件でも感想が付いたら、無料エリアの7番付近に引用して掲載する。**社会的証明はゼロと1件の差が最も大きい**。

## 07. タイトルの型

タイトルは自分の言葉ではなく、**読者が検索窓に打ち込む言葉**で作る。対象を狭めるほど売れる。

| 型 | 形 |
|---|---|
| 対象＋状況＋結果 | 「◯◯の人が△△だけで□□になるまでの全手順」 |
| 期間＋数字 | 「◯日で△△を□□にした記録（全データ公開）」 |
| 失敗の回避 | 「◯◯で私が溶かした△△と、同じ失敗を避ける□個のチェック」 |
| やらないことの提示 | 「◯◯をやめて△△に絞ったら□□になった話」 |
| 丸ごと公開 | 「実際に使っている◯◯のテンプレート□個をそのまま渡します」 |

- 「〜について」「〜のコツ」「〜まとめ」は避ける
- 抽象語（本質・思考法・マインド）は実績が立つまで使わない
- note内の表示では**前半20字前後**で切られる。重要語を前半へ
- ハッシュタグは内容と一致するものを3〜5個。無関係な人気タグは逆効果

## 08. 価格

note公式が2024年12月〜2025年11月の約30万件の有料記事を分析した結果、**売上上位20%の価格は実用系1,800円、読み物系980円**。「安くすれば売れる」は誤りで、100〜300円は「中身が薄い」シグナルになり手数料負けもする。

### 段階的値上げ

| ステージ | 状況 | 価格 | やること |
|---|---|---|---|
| STAGE 1 | 販売 0〜5冊 | 500〜980円 | 目的は売上でなく**感想と実例の収集**。「◯冊までこの価格」と明記 |
| STAGE 2 | 感想が3件 | 1,480円 | 無料エリアに感想を引用し、1〜2章追記してから上げる。値上げ予告で駆け込み需要 |
| STAGE 3 | 安定して売れる | 1,800〜2,980円 | 更新履歴・特典・質問対応で単価を正当化。メンバーシップへの入口に |

現在の価格設定範囲は100円〜50,000円（noteプレミアム会員は上限が更に高い）。**上げる方向にだけ、告知してから動かす**。

## 09. 手取りの現実

手数料は **①決済手数料 → ②note利用料 → ③振込手数料** の3段階で、②は①を引いた後の金額にかかる。振込手数料270円は*1回の振込ごと*で記事1本ごとではない。

以下はクレジットカード決済（5%）の場合：

| 販売価格 | 決済手数料 | note利用料10% | 手取り（振込前） | 率 |
|---|---|---|---|---|
| 500円 | −25 | −48 | 428円 | 85.5% |
| 980円 | −49 | −93 | 838円 | 85.5% |
| **1,800円** | −90 | −171 | **1,539円** | 85.5% |
| 2,980円 | −149 | −283 | 2,548円 | 85.5% |

- 携帯キャリア決済は15%、PayPayは7%程度。キャリア決済だと手取りは約76%まで落ちる
- note利用料は**有料記事・メンバーシップが10%、定期購読マガジンは20%**。同じ月額課金ならメンバーシップが有利
- 安い記事ほど振込手数料の相対負担が重い。100〜300円は労力に対してほぼ残らない

※手数料率は改定されることがある。実行前にnote公式ヘルプで現行レートを確認すること。

## 10. 30日の実行計画

新しい有料記事は1本も書かない。**既にある1本を売れる状態にし、そこへの道を10本引く**のが30日間の仕事。

### DAY 1–3｜書かずに、つなぐ
- 03の7か所の導線をすべて設置（過去記事全部の末尾ブロックを含む）
- noteプロフィールとXプロフィールを書き換える
- 無料記事＋有料記事をまとめたマガジンを1つ作る
- 現状の数値を記録：有料記事の月間ビュー・購入数・フォロワー数

### DAY 4–7｜有料記事の無料エリアを10ブロック構成に全面改稿
- 目次で有料部分の見出しを全公開する
- ノウハウを1つ、無料エリアに丸ごと出す
- 「向いていない人」を明記する
- 価格をSTAGE 1〜2に合わせ、値上げ予告を入れる
- 最初の購入者1名に感想を依頼する（社会的証明を1件作る）

### DAY 8–24｜無料記事を週3本 × 約2.5週 = 8〜10本
- 04の型の1・2・3番から着手（一次情報が最も推されやすい）
- 全記事に末尾の導線ブロックを入れる（テンプレ化して貼るだけにする）
- 公開ごとにXへ：本文は結論だけ、リンクは自分のリプ欄に
- 1日1回、同じテーマの他クリエイターの記事に具体的なコメントを残す

### DAY 25–30｜測って直す
- 有料記事ページのビューが月100を超えたか（超えていなければ導線の問題）
- ビュー100超で購入0なら、無料エリアの5番（目次公開）と6番（ノウハウ1つ公開）を見直す
- 最もビューが多かった無料記事のテーマを、次の有料記事のテーマにする
- 感想が3件たまったらSTAGE 2へ値上げ

## 11. 毎週見る数字は4つだけ

| 指標 | 見方 | 悪いときの打ち手 |
|---|---|---|
| 無料記事の合計ビュー | 月8,500PVが月3万円ラインの目安 | 記事本数を増やす／検索ワードを見直す |
| 有料記事ページのビュー | 目標850PV/月。100未満は導線不足 | 03の7か所を再点検、末尾ブロックの文言を変える |
| 購入率（購入 ÷ 有料記事ビュー） | 2%が基準。1%未満は記事の問題 | 無料エリアを05の構成に、目次を全公開 |
| 感想・言及の件数 | 0件か1件以上かが最大の分岐 | 購入者に直接依頼、特典と引き換えにする |

毎週同じ曜日に4つだけ記録する。**改善したのに数字を記録していないと、何が効いたか永久に分からない。**

## 12. やってはいけないこと

- ❌ **売れないからといって有料記事を増やす** — 入口がない状態で商品を増やしても分母は増えない
- ❌ **AIに丸投げした要約記事を量産する** — 2026年のレコメンド刷新で重複性の高い生成コンテンツは明確に推されにくくなった。AIは構成・校正・リサーチの補助まで
- ❌ **無料エリアをあらすじだけにする** — 中身が分からないものに人は払わない。目次は全公開が正解
- ❌ **逆に、無料エリアで全部満足させる** — 「もう十分」で終わる。解決策の入口までで止める
- ❌ **相互フォロー・スキ回りでフォロワーを集める** — 購買意欲ゼロの分母が増え、購入率が下がって判断を誤らせる
- ❌ **価格を上げ下げして反応を見る** — 既存購入者の信頼を失う。上げる方向にだけ、予告してから
- ❌ **DMで売り込む** — note・Xともに最も嫌われ、アカウントの評価も落とす
- ❌ **1〜2週間で判断して諦める** — 検索流入は公開から効き始めるまで1〜3か月。30日計画は「種を全部まく」期間で、収穫期はその後

### 最短で効く3つだけ選ぶなら

1. 過去の全無料記事の末尾に有料記事への導線ブロックを入れる
2. 有料記事の目次で有料部分の見出しを全公開する
3. 最初の購入者1名に感想をもらって無料エリアに載せる

いずれも数日で終わり、購入率に直接効く。
