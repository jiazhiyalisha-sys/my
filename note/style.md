# style.md — 公開済み4記事から抽出した文体（実物ベース）

`voice.md` が「何を書くか」、この `style.md` が「どう書くか」。
❷ライター・❸編集担当・`/記事化` は必ず両方読む。

出典：第1話 / 第2話 / 第3話 / 番外編（`note/titles/stock.md` にURL）

---

## 1. 段落と改行（これが一番の特徴）

- **1段落＝1〜3文。** 4文以上の段落はほぼ無い
- **段落ごとに空行。** 画面が文字で埋まらない
- **重要な一言は、単独行にする**

実物：
```
でも、ふとした瞬間に思うんです。

「このまま何年も、同じ生活を続けるのかな。」

何か始めたい気持ちはある。何をしたいのかは分からない。
```

- **短文を句点で連打してリズムを作る**
  「仕事が嫌いなわけじゃない。毎日ちゃんと働いている。生活もできている。」
  「転職する？副業する？資格を取る？起業する？投資をする？SNSを始める？」

## 2. 内心は鉤括弧で、単独行に置く

地の文で説明せず、そのとき頭に浮かんだ言葉をそのまま出す。

```
「このままでいいのかな。」
「私、なんで看護師になったんだろう？」
「あれ？私、なりたかった看護師になったはずなのに、社畜極めてない？」
「座るって、こんなに楽なことだったんだ。」
```

## 3. 回想の視点で書く

「今思えば」「今振り返ると」「当時の私は」を軸に、**過去の自分を今の自分が見る**構図。

- 「今思えば、ちょっと夢がないですよね。笑」
- 「当時の私は『まだ大丈夫』と思っていました。／今振り返ると、全然大丈夫じゃなかった。」

## 4. 数字は身体・時間・金額をそのまま出す

62kg → 52kg ／ 睡眠4〜5時間 ／ 初任給11万円 ／ 日勤18万円 ／ 同期30人 ／
2019年 ／ 2025年7月20日 ／ 15分 ／ 100万円 ／ 半年 ／ 1円

**丸めない。「約」を付けない。** 具体的な日付を出す。

## 5. 自虐と「笑」

重い話の直後に、軽く落とす。

- 「希望、全部外れました。笑」
- 「今思えば、ちょっと夢がないですよね。笑」
- 「先輩たち、歩くの早すぎない？　本当に競歩選手かと思いました。」

## 6. 誠実さの担保（信用の作り方）

- 「正直に言うと」「先に言っておくと」「結論から書きます」で逃げずに言う
- **都合の悪い事実を先に出す**：「半年間続けて、私は1円も稼げませんでした」
- **勧誘しないと明言する**：「スクール名は出しません。紹介もしません。この記事は勧誘ではない」
- **きれいにまとめない**：「『100万円払ってよかった！』と気持ちよく言えたら楽なんですが、それは嘘になります」

## 7. 読者への呼びかけ

- 冒頭で名指し：「もしあなたが今20代後半なら、一度は考えたことがあると思います」
- 締めで問い返す：「10年後も今と同じ働き方をしている自分を想像したとき、どう感じますか？」
- **読者を否定しない**：「『それでもいい』と思えるなら、それは素敵なことだと思います」

## 8. 表は使わない（noteのエディタが対応していない）

**noteに表機能は無い。** マークダウンの表を貼ると縦に潰れて読めなくなる。

第3話の「置き換え表」と番外編の「事実／想像」は、実際に崩れている。
公開済み記事を読み返して確認すること。

対比を書くときは、**縦並びの矢印形式**にする。

```
私がやっていたこと → 実際に必要だったこと

・課題を提出する → 誰かに渡す
・先生に見てもらう → 受け取る人に届ける
```

または、ラベルを見出しにして上下に並べる。

```
✕ 答えが出ない質問
　私は何がしたい？
　何が向いてる？

○ 答えが出る質問
　私は今の人生の、何を変えたい？
　今週、何を一つ触れる？
```

箇条書きは**有料ライン直前の予告**と**手順**に集中させ、地の文では使わない。

## 8-2. noteで使える書式・使えない書式

| | |
|---|---|
| 使える | 見出し、太字、引用、箇条書き、番号リスト、区切り線、コード、画像、埋め込み |
| **使えない** | **表**、色文字、文字サイズ変更、インデント |

**スマホで読まれる前提で組む。**
- 1行が長いと折り返しで読みにくい。**40〜50字で改行する**
- 段落ごとに空行
- 章の区切りは `――――――――――`、章内の小さな区切りは `◇`
- 見出しは `■` を付けると、目次でも本文でも見分けがつく
- 太字は1章に1〜2回まで。多いと効かなくなる

## 9. 「次回」で必ず引きを作る

末尾に「次回」の見出しを立て、**次回の中身を箇条書きで具体的に予告する**。
抽象的な予告にしない。

実物（第2話→第3話）：
```
そして、私がその状態から抜け出せたきっかけは、答えを見つけたことではありませんでした。

たった一つ、自分にする質問を変えただけです。
```

## 10. 記事の型（4記事に共通する骨格）

```
1. 読者の現状を名指し（「もしあなたが今〜なら」）
2. 内心を鉤括弧で1行
3. 私の話（時系列。数字と固有名詞を入れる）
4. つらかった事実を、身体で書く
5. 気づき（「私が変えるべきだったのは、〜ではありませんでした」）
6. 読者への問い
7. ここから先は〜（有料ラインの予告・箇条書き5〜6項目）
8. 手順／ワーク（有料部分）
9. 次回（具体的に箇条書きで予告）
```

## 11. 有料ラインの実際の形（重要）

**「本編＝無料／番外編＝有料」ではない。** 第3話（本編）にも有料ラインがある。

正しい基準：**その回の後半が「ワーク・手順・具体的なやり方」になるなら有料にする。**

有料ライン直前の定型：
```
ここから先は、私が実習中に実際にやっていたことを、そのまま使える1枚のワークにまとめました。

紙1枚、6ステップです。
　・STEP1｜今日、何があった？
　・STEP2｜そのとき、私は何を考えた？
　…
あわせて、
　・目を合わせられなかった私が、最初にやった「一瞬だけ」のやり方
　…
も書きます。
```

- 無料部分：状態・つらさ・気づきの入口まで
- 有料部分：STEP／記入欄／具体的なやり方／「効かない日にどうするか」

## 12. 手順の書き方（有料部分）

- **記入欄を実際に入れる**（`＿＿＿＿＿＿＿＿`）
- **できない前提から始める**：「いきなり『目を見る』は無理でした。だから眉の間を見るから始めました」
- **効かない日の逃げ道を必ず書く**：「このワークが、全く効かない日があります。そういう日は、やらなくていいです」
- **最後に安全弁を置く**：「環境と人に頼っていい。これは、逃げではありません」

## やってはいけない（4記事から逆算した禁止）

- 長い段落。3文を超えたら切る
- 誰かを責める・見下す。スクールも先輩も名指しで批判していない
- きれいな成功談にする。「失敗の記録です」と自分で言っている
- 抽象語で状態を説明する。身体で書く
- 次回予告を抽象的にする
