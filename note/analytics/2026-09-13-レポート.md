
**17アカウント中、医療職は「リハ人｜悩み続ける理学療法士」の1つだけ。**

残りは副業・起業・コンサル・占い・行政書士・飲食。
つまり **同業（発信する側）** であって、`voice.md` の読者像
「20代後半〜30代、看護師・会社員、人生を変えたい人」ではない。

「😃スマイル7😃 **フォロ**…」のように、名前に相互フォローを掲げたアカウントも混ざっている。

### フォロー45／フォロワー44 という比率

ほぼ1対1。これは**相互フォローで増えている状態**の典型。
「フォローが24→45」が自分のフォロー数なら、3日で21人を自分からフォローしたことになる。

**フォロワーは増える。でも、買わない。**

目標は「有料note50部・フォロワー1,000人」。
この増やし方でも1,000人には届く可能性がある。**だが50部には届かない。**
発信者同士のフォローは、購入にはつながらないため。

## 4. 見つかった不具合

### 第3話のタイトルが壊れている（要修正）

```
第3話：「何か始めたい。でも、何をしたらいいのかわからなかったので副業で100万出した
```

- **開き鉤括弧「に対して、閉じ鉤括弧が無い**
- 句点で終わっていない（公開済み他4本は句点で終わっている）

内容を足した判断自体は良い（「副業で100万出した」で具体性が上がった）。
体裁だけ直す。修正案：

```
第3話：「何か始めたい」と思った私が、副業に100万円払うまで。
```

## 5. 次の打ち手（3つ）

### ① ハッシュタグを看護師側に振り直す

現在のタグ（#副業 #AI #キャリア #自己投資）は、**発信者が多くいる場所**。
だから発信者に届いている。読者がいる場所に変える。

```
入れる：#看護師 #新人看護師 #看護学生 #夜勤 #看護師の悩み #転職
残す　：#看護師の副業 #失敗談 #選べる自分になるまで
外す　：#AI #キャリア #働き方 #自己投資
```

`#AI` は特に危険。AI発信者が大量にいるタグで、読者は一人もいない。

### ② Threadsを動かす

`05-販売.md` に告知文を用意したが、まだ投稿された形跡がない。
**noteの中だけで回すと、noteの発信者としか出会えない。**
看護師の読者はThreads側にいる。`/投稿` で10本作って流す。

### ③ 無料記事をもう1本挟む

無料2本が10〜11、有料3本が4〜8。
有料が3本続いたので、次は無料で間口を広げる。

在庫にあるこれが向いている（自分の話が不要で、読者のシーンそのもの）。
```

```

スキ数だけでは打ち手が決められない。noteのダッシュボードから：

- コメント数

特に **第3話と第4話が何部売れたか。** ここで300円が妥当だったかが決まる。
