# note 記事パイプライン

毎晩ひとりで回る。人間の入力は `素材.md` 一つだけ。

```
ログ.md ──読む──┐
型.md ──────────┤
禁止表現.md ────┼──> 出力/YYYY-MM-DD.md（3本の目次）
素材.md ────────┘         │
      ▲                   │
      │                   ▼
   人間が書く         ログ.md に追記（売れた数・仮説の当たり外れ）
                           │
                           └──> 次回の入力に戻る
```

| ファイル | 役割 | 誰が書くか |
|---|---|---|
| `型.md` | 売れている記事の8条件と読者像 | Claude（実績が溜まったら更新） |
| `禁止表現.md` | 既出の言い回し。使用禁止 | Claude（毎回追記） |
| `素材.md` | 経験・失敗・数字 | **人間。ここだけ** |
| `毎晩の指示.md` | 無人運転の手順と分岐の既定値 | 固定 |
| `出力/` | 3本の目次 | Claude（毎晩） |
| `ログ.md` | 売れた数と仮説の判定 | Claude が枠を作り、数字は人間が埋める |

## 動かし方

1. `素材.md` を埋める（空欄があってもよい。空欄の章は落ちる）
2. 毎晩 02:00 JST に自動実行。朝には `出力/` に3本並んでいる
3. 記事を公開したら `ログ.md` の該当行に PV / 販売数 / 売上 を書き込む
4. 次回はその数字を読んでから始まる

## 3本の枠

- 本1：仕事・数字の失敗
- 本2：人・関係の失敗
- 本3：**仮説枠**。答えの出ていない切り口に振る。外れたら二度と出さない
