❶〜❻のどの担当も、作業前に必ずこのファイルを読む。
ここが空欄のままだと、出力は一般論になる。運用開始前に埋めること。

- 失敗・遠回りした経験：（ここが記事の主原料になる。最低3つ書く）

  3.

## 2. 読者（1人に絞る）

- 誰：（年齢・職業・状況を1文で）

- その人がすでに試して失敗したこと：
- その人が使っている言葉：（読者本人が口にする表現をそのまま並べる）
- 読者が「自分のことだ」と気づく具体シーン：

## 3. 文体ルール

- 一人称：（私 / 僕 / 俺 / おれ）
- 語尾：（です・ます / だ・である / 混在）
- 一文の目安：40〜60字。ただし長短を混ぜる。同じ長さを3連続させない。
- 使う：具体的な固有名詞、金額、日付、会話の再現、自分の感情
- 使わない：下の NGリスト（`.claude/skills/note-edit/SKILL.md`）

## 4. 禁止事項（自分ルール）

- 例：他人を見下す書き方をしない
- 例：断定できない数字を出さない
- 例：クライアントが特定される情報を書かない

## 5. 商品・収益導線

- 販売中のもの：（有料note / 商品 / サービス / 価格）
- 記事から最終的に運びたい先：
- 1本あたりの目標：（フォロー○人 / 有料note○部 / メルマガ登録○件）
