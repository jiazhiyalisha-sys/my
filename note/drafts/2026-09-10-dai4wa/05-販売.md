## 2. 価格：**300円**

### 根拠

**① 第3話で予告した続きなので、前回より高くしない**
第4話を買うのは主に第3話の購入者。予告した内容に前回より高い値段を付けると
「約束の続きに追加料金」に見える。**第3話と同額か、それ以下。**

**② 目標50部。いまは単価より本数**
300円 × 50部 = 15,000円。第1話がスキ10個の段階なので、買う人の数を増やす局面。
500円にすると1部あたりは上がるが、本数が落ちて50部が遠のく。

**③ 本編300円／番外編500円 の階段を作る**
本編（物語）で連載を追わせ、番外編（ワーク・手順）で500円を取る。
既存の「1枚ワーク」がすでに500円の形なので、これで価格体系が揃う。

### 【要確認】第3話の価格

- 第3話が **300円** → そのまま300円で揃う
- 第3話が **500円** → 第4話も500円にするか、300円に下げる
  **下げるのは問題ない。上げるのは絶対にやらない。**

## 3. 有料ライン：**「触ったものを外に出した回数は、半年で0回です。」の直後**

（2026-09-11 変更。無料を厚くする方針に切り替えたため、6章の途中まで後ろにずらした）

```
（無料の最後）
触るところまでは、半年でずいぶんやりました。
AIも触った。営業の型も書き写した。
でも、触ったものを外に出した回数は、半年で0回です。

　→ ここから先は（予告6項目）

★ ここから有料 ★

■ 投稿の作り方を、24回習いました
私が半年間習っていたのは、AIとSNSを掛け合わせて、投稿する記事を作る方法でした。
投稿の作り方を、週に1回、24回習いました。
そして、1回も投稿していません。
```

### 字数

- **無料 3,291字（54%）／ 有料 2,773字**（本文6,145字）
- 依頼は「無料3,500字・有料2,500字くらい」。無料が約200字少ないが、
  これ以上ずらすと下の「別案」になる。埋めるための加筆はしていない。

### 構成がどう変わったか

| | 変更前 | 変更後 |
|---|---|---|
| 無料 | 診断（「出せない」）まで | **答え（「出す」）まで** |
| 有料 | 答え＋皮肉＋実例＋ワーク | 皮肉＋実例＋ワーク |
| 売り方 | 「答えを知るのに300円」 | **「答えは無料。やり方に300円」** |

無料部分で「出す」という結論まで読めるので、**拡散されやすくなった。**
そのぶん「答えが気になる」という購買動機は弱まり、
「自分もやってみたい」という動機に寄る。フォロワーが少ない今の段階ではこちらが合う。

### 有料側の1文目

```
私が半年間習っていたのは、AIとSNSを掛け合わせて、投稿する記事を作る方法でした。
投稿の作り方を、週に1回、24回習いました。
そして、1回も投稿していません。
```

記事で一番強い皮肉が、買った直後に来る。
1章の「この事実は、あとでもう一度出てきます」という伏線が、ここで回収される。
**無料側に伏線を置いて、有料側で回収する形になった。**

### 予告6項目も書き換えた

答え（「出す」）が無料で出てしまうため、予告の1〜2項目目を差し替えた。

```
・1章で「あとでもう一度出てきます」と書いた、あの事実の正体
・100万円で「退路を断った」はずの私が、実は断てていなかった理由
・「学んでから作る」をやめて、最初に外に出したもの
・出すものを決めるときに使った、3つの条件
・出すのが怖い日に、私がやっていたこと
・このやり方が効かない人について（ここが一番大事です）
```

### 別案（数字をぴったりに寄せる場合）

ラインをもう1ブロック後ろ（「これが、知識と稼ぐの間にあったものでした。」の直後）に
ずらすと **無料3,451字／有料2,613字** になり、依頼の数字にほぼ一致する。

ただし2つ失う。
- 記事最大の皮肉（24回習って投稿0回）が無料になり、**有料の1文目が弱くなる**
- 予告の1項目目「あの事実の正体」がネタバレになるため、書き換えが必要

**拡散をさらに優先するならこちら。** 現状の3,291字でも「無料が厚い」設計は成立している。

## 6. Threads告知文（❶投稿担当の「告知」型に渡す）

```
投稿の作り方を、週1回、24回習いました。

100万円のスクールに半年通って、1円も稼げなかった話の続きを書きました。

```

- 1行目だけで意味が通る（`/投稿` の必須条件）
- 2行目で落とす
- 数字だけで構成し、煽り文句を入れていない
- **公開後に投稿する。** 先に告知すると以降の投稿が伸びない

## 7. ハッシュタグ（10個）

```
#選べる自分になるまで
#看護師
#看護師の副業
#副業
#自己投資
#AI
#失敗談
#キャリア
#働き方
#20代
```

### 組み方（3層＋連載タグ）

**① 連載タグ（1個）— これが一番効く**
`#選べる自分になるまで`
第2話の本人の言葉「『選べる自分』になりたかった。これが一番近いです。」から取った。
**公開済みの第1話〜番外編にも、後から同じタグを追加する。**
タグページが連載の目次になり、1本読んだ人が他の記事へ回遊する。

**② 自分の属性（3個）**
`#看護師` `#看護師の副業` `#20代`
読者が実際に検索する語。`#看護師の副業` は母数が小さいぶん、刺さる人に確実に届く。

**③ 記事の中身（4個）**
`#副業` `#自己投資` `#AI` `#失敗談`
- `#自己投資` … 高額スクールに払った人・払おうとしている人が見る
- `#失敗談` … この記事の性格そのもの。成功談タグの中で逆に目立つ

**④ 広めのタグ（2個）**
`#キャリア` `#働き方`
母数が大きく埋もれやすいが、外側の会社員読者を拾う枠として2個だけ入れる。

### 入れないもの

- `#エッセイ` `#日記` `#コラム` … 母数が巨大で埋もれる。読者層も合わない
- `#稼ぐ` `#不労所得` `#月収` … 稼いでいない記事に付けると期待とズレる。離脱される
- `#スキしてね` `#フォロバ` … 数字目的のタグは、読む気のない人を連れてくる
- 記事の中身と関係ないタグ全般
  **関係ない人が流入すると読了率が下がる。** タグは多いほど良いわけではない

### note公式のお題タグについて

noteは時期ごとに公式のお題タグ（コンテストや企画）を出していて、
そこからピックアップされると露出が跳ねる。

**ただし、内容が時期で変わるため、こちらでは確認できない**
（この環境からnote.comにアクセスできないため）。
投稿前にnoteのトップページか「お題・コンテスト」欄を見て、
**仕事・キャリア・お金・挑戦系のお題が出ていれば1つ足す**。
その場合は上の10個から `#20代` を外して入れ替える。
