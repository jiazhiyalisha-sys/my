## 記録の形式

各回、以下をそのままコピーして埋める。

```
## YYYY-MM-DD 第N回

### 出した3本
| # | タイトル | 公開日 | PV | 有料販売数 | 売上 |
|---|---------|-------|----|----------|------|
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3（仮説枠） |  |  |  |  |  |

### ❸の仮説
仮説：
判定：当たり / 外れ / 保留
根拠（数字で）：

### 分かったこと（1行）

### 次回に渡すもの
- 効いた要素：
- 落とす要素：
- 次に試す仮説：
```

---

## 判定基準

- **当たり**：仮説枠の1本が、他2本の販売数の中央値を上回った
- **外れ**：下回った
- **保留**：公開から7日未満、またはPVが3本とも100未満（母数不足）

保留は次回も同じ仮説で再提出してよい。外れた仮説は二度出さない。
