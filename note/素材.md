# 素材

**このファイルだけが人間の入力。**
ここに書いたことしか記事には入らない。書いていないことは生成されない（推測・創作は禁止）。

書き方のルール：
- 数字は丸めない。「約3年」ではなく「2年8ヶ月」
- 失敗は結果まで書く。「うまくいかなかった」ではなく「何がどれだけ減ったか」
- 「なし」と書いた項目は記事から章ごと落とす

---

## 🚫 最優先制約（2026-09-10 追加）

**「使わないと決めていること」に法的制約が入った。これが他の全ての素材に優先する。**

- **不動産の件は弁護士と協議中。詳しくは書けない**
- **「詐欺」に当てはまる記述はしない**
- **自慢話はしない**

→ 影響：**1億2000万の経緯を核にした記事は出せない。**
金額・相手・経緯・「詐欺」という語のいずれも書かない。
負債が残っている事実のみ、金額を伏せて言及する（例：「返済が残っている」）。
係争中の案件を公開の場で特徴づけると、手続に影響しうるため。

## この素材から導かれる制約

1. **1億2000万は記事の核にできない**（法的制約）。金額を伏せた「返済が残っている」のみ可
2. **S1は勝ちとして書かない**（自慢話禁止）。「6ヶ月で30万 → 再現できると読んだ → 300万」という負けの導線としてのみ使う
3. **S9により、書き手は常勤を降りている（確定）**。常勤→非常勤、月35万。「まだ抜けていない」という前提は無効
4. **S17が空**＝いま試していることが未記入。本3の章7は現状ほぼ空になる。ここを埋めると本3が完成する
