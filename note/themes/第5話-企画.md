## 2. いま書ける一番強い素材＝この2週間の数字そのもの

第4話で「出す」と書いた人間が、実際に出した。その結果がこれ。

```
公開       5本（9/4〜9/11）
ビュー     公開中5本で402（全体695のうち293は削除済み記事）
スキ       61
コメント   2（どちらも第1話）
フォロワー 44人
売上       200円（購入1部）
```

**「出したら世界が変わった」ではなく「出したら200円だった」。**

この落差を、失望としてではなく事実として書く。
連載の他のどの回よりも珍しい内容になる。**普通、誰もこれを書かない。**

### 予告①「想像していなかった反応」の正体

フォロワー44人の内訳が、狙っていた読者と違った。

通知に出た17アカウントのうち、医療職は1つだけ。
残りは副業・起業・コンサル・占い・行政書士。**つまり、発信する側の人たち。**

**看護師に向けて書いたのに、来たのは看護師じゃなかった。**

これが「想像していなかった反応」の中身。予告と完全に噛み合う。

### 予告②③へのつなぎ方

読者はここで当然こう思う。

> 200円のために、そこまでやるのか。

その問いに、非常勤を選んだ話が答える。
**お金のためではなく、時間と選択肢のために働き方を変えた**という話だから。

2つのテーマがきれいに1本の線になる。

## 3. 価格：**無料**（強く推奨）

### 根拠はデータ

```
第1話（無料）  193ビュー / スキ17
第2話（無料）   87ビュー / スキ11
第3話（300円）  63ビュー / スキ8
番外編（500円） 33ビュー / スキ4
第4話（300円）  26ビュー / スキ9
```

- **有料が3本続いて、ビューが193→26まで落ちている**
- 50部に必要なのは約3,300ビュー。現在の有料3本の合計は122ビュー（**27倍の距離**）
- いまは売る段階ではなく、読まれる数を増やす段階

### もう一つの理由

**この回の内容は「無料だからこそ効く」。**

売上200円を公開する記事を300円で売ると、
「200円しか稼げていない話を300円で買わせるのか」という形になる。
無料で出すほうが、内容と姿勢が一致する。

## 5-0. 【2026-09-16 更新】回答を受けて分かったこと

### ① 記事の背骨が確定した：1回目は「逃げ」、2回目は「選択」

```
1回目  2023年12月末〜2024年4月末
　その前に携帯ショップの店員を3ヶ月。結果が出ず、嫌すぎて逃げた。
　逃げ込んだ先が、非常勤だった。

2回目  2026年4月〜現在
　自分で事業を持ちたくなった。フリーランスになった。
```

**同じ「非常勤」に見えて、中身が正反対。** これがこの記事の背骨。

```
第5話の1行：非常勤を選んだのは2回目です。でも、1回目とはまったく違いました。
```

この構造があると、予告③「収入が減ると分かっていて選べた理由」の答えが立つ。
**1回目は減ることから逃げた。2回目は減ることを引き受けた。**

### ② 記事の核になる数字が出た

常勤     総額43万円 / 手取り38万円前後
非常勤   月35万円（現在）

**「月8万円減らして、時間を買った」。** 予告③「収入が減ると分かっていて、それでも選べた理由」に
そのまま答える数字。第3話の100万円と並ぶ、この連載で2番目に大きい金額。

## 6. 判断が要る1点：売上200円を公開するか

**公開を推奨する。** ただし、判断はARYUNさんのもの。

**公開する理由**
- 第3話で「1円」と書いている。200円を隠すほうが不自然
- この連載の価値は「失敗の記録」であること。数字を隠した瞬間に性格が変わる
- 1円 → 200円 は、小さいが**事実として前進している**

**公開しないほうがいい場合**
- 「この人から買っても意味なさそう」と思われるリスクはある
- ただし、そう思う人はもともと買わない層

書くなら、金額の大小を言い訳しない。
**「200円でした」と書いて、次の行で理由を説明しない。** 説明すると言い訳に見える。
