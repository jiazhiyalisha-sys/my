## 2. いま書ける一番強い素材＝この2週間の数字そのもの

第4話で「出す」と書いた人間が、実際に出した。その結果がこれ。

```
公開       5本（9/4〜9/11）
ビュー     公開中5本で402（全体695のうち293は削除済み記事）
スキ       61
コメント   2（どちらも第1話）
フォロワー 44人
売上       200円（購入1部）
```

**「出したら世界が変わった」ではなく「出したら200円だった」。**

この落差を、失望としてではなく事実として書く。
連載の他のどの回よりも珍しい内容になる。**普通、誰もこれを書かない。**

### 予告①「想像していなかった反応」の正体

フォロワー44人の内訳が、狙っていた読者と違った。

通知に出た17アカウントのうち、医療職は1つだけ。
残りは副業・起業・コンサル・占い・行政書士。**つまり、発信する側の人たち。**

**看護師に向けて書いたのに、来たのは看護師じゃなかった。**

これが「想像していなかった反応」の中身。予告と完全に噛み合う。

### 予告②③へのつなぎ方

読者はここで当然こう思う。

> 200円のために、そこまでやるのか。

その問いに、非常勤を選んだ話が答える。
**お金のためではなく、時間と選択肢のために働き方を変えた**という話だから。

2つのテーマがきれいに1本の線になる。

## 3. 価格：**無料**（強く推奨）

### 根拠はデータ

```
第1話（無料）  193ビュー / スキ17
第2話（無料）   87ビュー / スキ11
第3話（300円）  63ビュー / スキ8
番外編（500円） 33ビュー / スキ4
第4話（300円）  26ビュー / スキ9
```

- **有料が3本続いて、ビューが193→26まで落ちている**
- 50部に必要なのは約3,300ビュー。現在の有料3本の合計は122ビュー（**27倍の距離**）
- いまは売る段階ではなく、読まれる数を増やす段階

### もう一つの理由

**この回の内容は「無料だからこそ効く」。**

売上200円を公開する記事を300円で売ると、
「200円しか稼げていない話を300円で買わせるのか」という形になる。
無料で出すほうが、内容と姿勢が一致する。

## 6. 判断が要る1点：売上200円を公開するか

**公開を推奨する。** ただし、判断はARYUNさんのもの。

**公開する理由**
- 第3話で「1円」と書いている。200円を隠すほうが不自然
- この連載の価値は「失敗の記録」であること。数字を隠した瞬間に性格が変わる
- 1円 → 200円 は、小さいが**事実として前進している**

**公開しないほうがいい場合**
- 「この人から買っても意味なさそう」と思われるリスクはある
- ただし、そう思う人はもともと買わない層

書くなら、金額の大小を言い訳しない。
**「200円でした」と書いて、次の行で理由を説明しない。** 説明すると言い訳に見える。
