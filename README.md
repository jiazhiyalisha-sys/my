# note運用

note と Threads の運用を、6つの担当に分けて回すための仕組み。
各担当は Claude Code のスキルとして定義してあり、スラッシュコマンドで呼び出す。

## 担当一覧

| | 担当 | コマンド | やること |
|---|---|---|---|
| ❶ | 投稿担当 | `/note-post` | Threads投稿を10本一括生成（型を10種散らす） |
| ❷ | ライター | `/note-write` | note本文を8,000字で執筆 |
| ❸ | 編集担当 | `/note-edit` | AI臭い言い回しを洗い出して修正 |
| ❹ | 分析担当 | `/note-analyze` | 伸びた投稿を分析して次に活かす |
| ❺ | 企画担当 | `/note-plan` | 次に書くテーマの候補出し |
| ❻ | 販売担当 | `/note-sell` | タイトル案と有料ラインの設計 |

## 回し方（1サイクル）

```
❺企画 → ❶投稿(反応テスト) → ❷執筆 → ❸編集 → ❻販売設計 → 公開 → ❹分析 → ❺企画 …
```

ポイントは2つ。

1. **❶を❷の前に置く。** Threadsで先に反応を見てから8,000字を書く。反応がゼロのテーマに8,000字かけない。
2. **❹の結果を `note/voice.md` に書き戻す。** 書き戻さない分析は次に活きない。

## 最初にやること

`note/voice.md` を埋める。全担当がここを読む。
特に「失敗・遠回りした経験」と「読者」が空欄だと、出力は一般論にしかならない。

## ファイル配置

```
note/
  voice.md              全担当が参照する設定（読者・文体・実績・商品）
  themes/backlog.md     企画ストック / 既出テーマ管理
  drafts/               note本文の原稿
  threads/              Threads投稿案（日付ごと）
  analytics/log.csv     投稿ごとの数値ログ
.claude/skills/         各担当の定義
```
