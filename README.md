# note 販売戦略

エッセイ系有料 note（「人生を変える」系／Threads 単独集客／有料2〜5本）が
1冊売れて止まっている状態を立て直すための資料。2冊組。

| ファイル | 内容 |
|---|---|
| `note-funnel.html` | **動線設計図** — 露出から購入までの6層と、どこを直すと何倍になるか |
| `note-recognition.html` | **別冊02・知ってくれる人のつくり方** — 上記「層0／層1」の中身。認知形成 |

動線が整っていても知ってくれる人がいなければ売れず、
知ってくれる人がいても動線がなければ買えない。両方必要。
