# note 売上分析

note のダッシュボードから書き出したCSVを読み込み、「どの記事が一番売れているか」を
**売上金額 / 販売数 / 転換率（PV→購入）** の3つの基準で集計します。

出力イメージ: [`reports/SAMPLE_REPORT.md`](reports/SAMPLE_REPORT.md)（ダミーデータによるサンプル）

## 使い方

1. note の「ダッシュボード」→「売上管理」から販売履歴のCSVを書き出す
2. あわせて「アクセス状況」のCSVも書き出す（転換率の算出に必要。任意）
3. 両方を `data/` に置く（→ [`data/README.md`](data/README.md)）
4. 実行する

```bash
python3 analyze_note_sales.py
```

標準ライブラリだけで動きます（pandas等のインストール不要）。動作確認は Python 3.11。
結果は標準出力と `reports/note_sales_report.md` に出ます。

### オプション

| オプション | 既定 | 説明 |
|---|---|---|
| `--data-dir DIR` | `data` | CSVを探すディレクトリ |
| `--top N` | `10` | 各ランキングの表示件数 |
| `--min-views N` | `100` | 転換率ランキングに載せるPVの下限 |
| `--include-support` | off | サポート等、記事以外の売上も集計に含める |
| `--out PATH` | `reports/note_sales_report.md` | レポートの出力先 |

## 出力される内容

- **結論** … 3基準それぞれの1位
- **全体サマリー** … 売上合計・販売数・平均単価・全体転換率
- **基準別ランキング** … 売上金額 / 販売数 / 転換率
- **総合ランキング** … 3指標を0-100の相対スコアに直して平均したもの
- **価格帯別の傾向** … 価格帯ごとの売上・転換率
- **月別推移** … 日付列がある場合
- **データについて** … 読み込んだファイル、PV不明の記事数、二重計上の警告など

## 対応しているCSVの形

列名の表記ゆれ（`ビュー`/`全体ビュー`/`PV`、`販売数`/`購入数` など）と、
UTF-8 / UTF-8 BOM / Shift_JIS(cp932) を自動判別します。見出し行の前に説明行が
入っていても読み飛ばします。売上CSVは「1行＝1購入」の明細形式でも、
「1行＝1記事」の集計形式でも構いません。

読み込めないCSVがあった場合は、レポート末尾の「データについて」に理由付きで
記録されます（黙って無視はしません）。

## 注意

- **このリポジトリは public です。** `data/*.csv` は `.gitignore` で追跡対象外に
  してありますが、共有する前に中身を確認してください。
- 売上金額は「手数料を引く前の販売価格ベース」で集計します。振込金額の列がある
  場合は、サマリーに「振込ベース合計」として併記します。
